# Twi (Asante Twi & Akuapem Twi)

## Overview
Twi is a dialect of the Akan language, spoken by ~9 million people in southern and central Ghana. Asante Twi (Kumasi region) and Akuapem Twi are the main variants — mutually intelligible.

## Pronunciation Guide
- **a** — like "a" in "father"
- **e** — like "e" in "bet"
- **ɛ** — like "e" in "bed" (more open)
- **i** — like "ee" in "see"
- **o** — like "o" in "go"
- **ɔ** — like "aw" in "law"
- **u** — like "oo" in "food"
- **hy** — like "sh" in "ship"
- **dw** — like "j" with rounded lips
- **ky** — like "ch" in "chip"
- **gy** — like "j" in "jump"
- **tw** — like "ch" with rounded lips
- **-hw** — like "f" (in some dialects) or "hw"
- Tones are important but not marked — context usually clarifies
