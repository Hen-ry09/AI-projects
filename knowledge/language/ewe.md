# Ewe Language Guide

## Overview
Ewe is spoken by ~3 million people in southeastern Ghana (Volta Region) and southern Togo. It belongs to the Gbe language family.

## Pronunciation Guide
- **a** — like "a" in "father"
- **e** — like "e" in "bet"
- **ɛ** — like "e" in "bed"
- **i** — like "ee" in "see"
- **o** — like "o" in "go"
- **ɔ** — like "aw" in "law"
- **u** — like "oo" in "food"
- **dz** — like "ds" in "woods"
- **ts** — like "ts" in "cats"
- **ny** — like "ny" in "canyon"
- **ŋ** — like "ng" in "sing"
- **v** — like "v" but with lips (bilabial)
- **f** — like "f" but with lips (bilabial)
- Ewe is a tonal language — tones change meaning
